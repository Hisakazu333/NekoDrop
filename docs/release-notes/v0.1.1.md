# NekoDrop v0.1.1

**局域网点对点加密文件传输 · 局域网文件直传，端到端加密，零云端**
**Encrypted peer-to-peer file transfer for your local network — end-to-end encrypted, no cloud, no third party.**

---

## ✨ 本版亮点 / What's New

### 中文

- **跨网收件（iroh）**：收件可选「直连打洞」或「中继」模式，不同网络也能互发；直连模式零第三方参与，中继模式仅转发密文
- **文本快送闭环**：输入框直接打字 ⌘↩ 发送，接收端自动进剪贴板，秒传链接/代码/口令
- **传输排队 + 暂停/继续**：忙线自动排队（重启不丢），暂停后从断点续传，不用从头再来
- **拖拽直发**：把文件拖到侧栏设备行上松手即发
- **发送限速**：设置里可限 KB/s，给其他应用让带宽
- **设备备注名**：给已配对设备起别名，侧栏优先显示
- **按设备归档**：收到的文件可自动放入「接收目录/设备名/」
- **应用内更新检查**：有新版本会在设置页提示
- **新增 Intel Mac 安装包**

### English

- **Cross-network receiving (iroh)**: optional direct (hole-punching, zero third party) or relay mode (n0 public relays, ciphertext only) so devices on different networks can still connect
- **Text quick-send loop**: type in the composer and hit ⌘↩; received snippets land in your clipboard automatically
- **Transfer queue + pause/resume**: sends queue while busy (and survive restarts); pausing resumes from verified chunks instead of restarting
- **Drag-to-device send**: drop files straight onto a device row in the sidebar
- **Send throttling**: cap the send rate in settings to leave bandwidth for everything else
- **Device aliases**: rename paired devices; aliases take precedence in the sidebar
- **Organize by device**: optionally file incoming transfers into `receive-dir/<device>/`
- **In-app update check** with a link in Settings
- **New: Intel Mac build**

## 🔒 安全说明 / Security

- 每次传输独立加密会话：X25519 密钥交换 + Ed25519 设备签名 + ChaCha20-Poly1305，密钥只在你设备上
- Every transfer runs its own encrypted session: X25519 key exchange, Ed25519 device identity, ChaCha20-Poly1305. Keys never leave your devices.
- 默认零云端零遥测；跨网中继模式仅转发密文，元数据对中继可见（设置里已注明）
- No cloud, no telemetry by default; the optional relay mode forwards ciphertext only (metadata is visible to the relay, as noted in Settings)
- 代码 Apache-2.0 开源，欢迎审计 / Open source under Apache-2.0 — audits welcome

## ⚠️ 已知限制 / Known Limitations

- 安装包**未签名**：macOS 首次打开请右键 →「打开」；Windows SmartScreen 提示时选「仍要运行」。正式签名需要开发者证书，后续版本解决
- Builds are **unsigned**: on macOS right-click → Open for the first launch; on Windows choose "Run anyway" in SmartScreen. Signed builds are planned
- 自动更新暂未启用（依赖签名）/ Auto-update is not enabled yet (requires signing)
